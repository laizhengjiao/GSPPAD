## Data Availability
The global surface Poaceae pollen abundance dataset used in this study is publicly available via Zenodo:
[https://doi.org/10.5281/zenodo.17840721](https://doi.org/10.5281/zenodo.17840721)
All results predicted by the model can be accessed at https://doi.org/10.6084/m9.figshare.32969849.
